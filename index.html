01 — About

More than just a scripter.

For the last 5 years, I've been immersed in software development. What started as general programming evolved into a deep focus on Roblox Studio and Luau, where I've spent the last 3 years engineering gameplay systems, data management, UI systems, and core gameplay loops.

Alongside scripting, I design and build Roblox interfaces. I use Figma to plan layouts and visual systems before bringing them into Roblox Studio, allowing me to handle both the design and implementation of a UI from start to finish.

Beyond Roblox, I work with C++ and Python to build desktop utilities. I prioritize clean architecture, polished interfaces, and clear communication in every project I work on.
